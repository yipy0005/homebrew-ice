# homebrew-ice

Homebrew tap for an unofficial macOS 27 build of [Ice](https://github.com/yipy0005/Ice) (fork of jordanbaird/Ice).

    brew tap yipy0005/ice
    brew install --cask ice

The app is ad hoc signed and not notarized; the cask removes the quarantine flag on install. Conflicts with the `jordanbaird-ice` cask.
